# FORGE

**Every interface. One reference.**

Biblioteca visual bilingue de componentes, padrões, gráficos, multimédia, APIs e utilitários para desenvolvimento web.

## Funcionalidades

- Mais de 120 entradas com rotas estáticas em português e inglês
- Shell persistente com sidebar recolhível e navegação móvel
- Command palette global com `Ctrl/Cmd + K`
- Temas claro e escuro persistentes
- Documentação com Preview, Code, Accessibility e Usage
- Formulários, tabela empresarial, galeria multimédia e API Explorer interativos
- Biblioteca de gráficos SVG sem dependências adicionais
- Playground configurável, bookmarks e feedback de cópia
- Layout responsivo e suporte a `prefers-reduced-motion`

## Stack

- Next.js 16 e React 19
- TypeScript
- Tailwind CSS 4
- Lucide React

## Executar

```bash
npm install
npm run dev
```

Abra `http://localhost:3000`. A raiz redireciona para `/pt`; a versão inglesa está em `/en`.

## Validar

```bash
npm run lint
npm run build
```

Todo o conteúdo é local. O API Explorer simula pedidos sem depender de backend ou serviços externos.
