# 🎨 UI Templates Collection

Bem-vindo ao meu repositório central de *Templates* de Interface de Utilizador! 
Este repositório (Monorepo) aloja várias arquiteturas e interfaces ultra-premium desenvolvidas em **Next.js, Tailwind CSS e TypeScript**.

## 🚀 Templates Disponíveis

### 1. [Template Arquitetura & Fotografia](./template-arquitetura-foto)
Um portefólio imersivo e de alta fidelidade desenhado para arquitetos e fotógrafos. Focado no uso de grandes imagens, navegação fluída, alvenaria (*masonry*) de imagens em ecrã inteiro e texturas de vidro canelado (*fluted glass*).

### 2. [Template AI Landing Page](./template-ai-landing)
Uma *Landing Page* SaaS moderna em *Dark Mode* para plataformas de Inteligência Artificial. Inclui secções de preços (*pricing*), grelhas bento (*bento grids*), e destaques visuais com gradientes em tons de púrpura, desenhada para máxima conversão.

### 3. [Template Auth Screens](./template-auth-screens)
Ecrãs de autenticação luxuosos com simulações de UI baseadas em *glassmorphism* (efeito de vidro). Perfeito para ecrãs de *login* e registo envolventes em aplicações web modernas.

### 4. [Template Analytics Dashboard](./template-analytics-dashboard)
Um *dashboard* de análise de dados avançado, ultrarrealista e em *Dark Mode*. Inclui gráficos vetoriais nativos, tipografia técnica, seis secções distintas de KPI (Overview, Performance, Conversões, Inventário) e uma tabela de relatórios super detalhada.

## 🛠️ Stack Tecnológico
- **Framework:** Next.js 15 (App Router)
- **Estilização:** Tailwind CSS (v4) / Turbopack
- **Linguagem:** TypeScript
- **Ícones:** Lucide React

## 💻 Como executar localmente

Como este é um repositório composto por múltiplos projetos isolados, deves navegar para o template que pretendes executar e instalar as dependências.

Por exemplo, para correr o `template-ai-landing`:

```bash
cd template-ai-landing
npm install
npm run dev
```

O projeto ficará disponível em `http://localhost:3000`.
