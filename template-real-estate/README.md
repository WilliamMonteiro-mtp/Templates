# Aethelred Properties Template 🏡✨

Bem-vindo ao **Aethelred Properties**, um template frontend moderno e sofisticado para agências imobiliárias de luxo, desenhado com foco em alta conversão, *premium feel* e arquitetura escalável.

Este template foi integralmente construído em **Next.js 15 (App Router)** e estilizado com **Tailwind CSS v4**, garantindo uma estética minimalista e um carregamento ultrarrápido.

---

## 🎨 Arquitetura de Design & Estética
O design baseia-se numa paleta cromática terra/bege que transmite sofisticação e conforto, conjugada com fontes contrastantes:

*   **Tipografia:** `Times New Roman` (Serif) para os cabeçalhos, trazendo autoridade e luxo clássico, e uma fonte `sans-serif` moderna e limpa para leitura de detalhes e UI.
*   **Paleta de Cores (`globals.css`):**
    *   Fundo principal (Void): `#F5F3EC` (Creme luxuoso)
    *   Texto principal: `#1C1D18` (Verde azeitona muito escuro/quase preto)
    *   Destaques escuros: `#1E201B`
*   **Sombras e Componentes:** Sombras expansivas em componentes fulcrais, como a caixa de pesquisa, originando um aspeto flutuante (morfismo suave).

## 🚀 Funcionalidades Principais

1.  **Hero Section Expansiva:** Imagem de fundo gigante com gradientes subtis para a leitura do título.
2.  **Módulo de Pesquisa Flutuante:** Barra de procura integrada para localização, tipologia, preço e quartos com botão call-to-action imediato.
3.  **Layouts Assimétricos e Grelhas (Grids):**
    *   Exposição lado a lado de propriedades com etiquetas flutuantes ("For Sale", "Featured").
    *   Grelha de exploração por estilo de vida com micro-animações de ampliação (*scale on hover*).
4.  **Apresentação da Agência & Equipa:** Cartões de imagem intercalados (estilo editorial).
5.  **Secção Editorial Destacada:** Semelhante a uma revista de luxo, focada num imóvel espetacular.
6.  **Testemunhos e Newsletter:** Construção de confiança (*social proof*) e *lead generation* contínua na parte inferior do site.

## 🛠️ Tecnologias Utilizadas

- [Next.js 15](https://nextjs.org/) (React Framework)
- [Tailwind CSS v4](https://tailwindcss.com/)
- [Lucide Icons](https://lucide.dev/)
- [TypeScript](https://www.typescriptlang.org/)

## ⚙️ Como Começar

Uma vez que este template utiliza tecnologias recentes, segue os passos abaixo para instalar e rodar localmente no teu ambiente de desenvolvimento:

```bash
# 1. Instalar todas as dependências à força (caso haja conflitos de cache do portefólio original)
npm install --force

# 2. Iniciar o servidor de desenvolvimento
npm run dev
```

Após o arranque, podes visitar [http://localhost:3000](http://localhost:3000) e verificar o resultado em tempo real.
