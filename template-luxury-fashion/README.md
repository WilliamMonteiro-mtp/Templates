# ÉLAN — Luxury Fashion Template

Template editorial bilingue para lojas de moda e acessórios de luxo, desenvolvido com Next.js, React, TypeScript e Tailwind CSS.

## Funcionalidades

- Experiência responsiva para computador, tablet e telemóvel
- Conteúdo completo em português (`/pt`) e inglês (`/en`)
- Catálogo com filtros por categoria
- Favoritos e contador do saco de compras
- Secções editoriais, revista e newsletter
- Páginas geradas estaticamente para os dois idiomas

## Executar localmente

```bash
npm install
npm run dev
```

Abra `http://localhost:3000`. A página inicial redireciona automaticamente para `/pt`.

## Validar

```bash
npm run lint
npm run build
```
