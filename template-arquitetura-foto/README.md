# Template Arquitetura Foto

Um template sofisticado, minimalista e visualmente deslumbrante projetado especificamente para Portfólios de Arquitetura e Fotografia, utilizando **Next.js** e **Tailwind CSS**.

## Funcionalidades
- Design centrado na imagem, com tipografia moderna e elegante.
- Galerias interativas (Grid layouts e Masonry).
- Transições de ecrã suaves e animações de scroll.
- Secção sobre o autor e página de contacto com formulário.

## Como Correr Localmente

1. Instalar as dependências:
   ```bash
   npm install
   ```
2. Iniciar o servidor de desenvolvimento:
   ```bash
   npm run dev
   ```
3. Abrir [http://localhost:3000](http://localhost:3000) no browser.
