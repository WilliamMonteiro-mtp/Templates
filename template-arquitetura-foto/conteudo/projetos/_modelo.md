# Modelo de projeto pessoal

Copia os campos para um bloco `### project.{slug}` em `conteudo/dados.md` (secção 12).

Em `problem`, `approach` e `outcome` o texto fica numa só linha: `||` separa parágrafos na página do projeto e `termo` marca nomes técnicos.

- slug:
- featured: false
- status: (idea | design | building | paused | live | done)
- yearStart:
- yearEnd: (ou em curso)
- cover: null
- repo: null
- demo: null
- tags: []
